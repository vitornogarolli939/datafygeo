# Fora do site — onde as IAs vão "ouvir falar" da Datafy

60–80% das citações em respostas de IA vêm de fora do site da marca. Vocês já têm ativos que a maioria não tem. Ordem por impacto ÷ esforço.

## 1. Canal DATA7 (@data7apps) — já existe, precisa ser "legível" pela IA
- Para cada vídeo sobre a API: título com a pergunta exata ("Como conectar WhatsApp API oficial no n8n em 15 minutos"), descrição com 3 parágrafos de texto (não só links), capítulos com timestamps, e link para a página correspondente em conteudo.datafyapi.com.br.
- Transcrição limpa no YouTube (a IA do Google lê transcrição).
- Para cada página do plano-40, um vídeo curto (3–8 min) mostrando na tela. Não precisa produção: gravação de tela + voz.
- Pedir ao Claude Code: "liste os vídeos do canal sobre a API e sugira novos títulos com a pergunta exata do perguntas.csv".

## 2. Vídeo orgânico Nine Labs (youtube.com/watch?v=FcAwJqVHNoU)
- Agradecer publicamente, embutir na página-mãe e na página de n8n, e oferecer ao criador: acesso estendido, um caso real para o próximo vídeo ("áudio, imagem, recebimento") que ele mesmo prometeu no final.
- Pedir para ele fixar o link da doc e da página de n8n na descrição.

## 3. Comunidade n8n (a maior fonte de citações para a persona automação)
- Publicar workflow templates oficiais no n8n.io/workflows: "WhatsApp oficial via Datafy — receber e responder", "Handoff humano com smb_message_echoes", "Notificação de pedido com template". Templates do n8n são indexados e citados por IAs.
- Responder no community.n8n.io toda thread sobre "WhatsApp API oficial", "Evolution ban", "Cloud API webhook" com resposta útil e link para a página certa. Uma pessoa, 2 h/semana.
- Mesmo para Make (scenario templates) e Zapier (app listing público).

## 4. GitHub
- Repositório público datafy-api com: README explicando o espelho da Meta, exemplos em Node/Python/PHP, o código de validação HMAC, um exemplo de agente de IA com handoff. Estrela de alunos da DATA7.
- Coleção pública no Postman + OpenAPI (já existe o download na doc — publicar no Postman Public Network e no APIs.guru).

## 5. Alunos da DATA7 (6.000+)
- Os alunos que usam a Datafy em SaaS próprios são casos reais. Pedir 5 depoimentos com números (números conectados, mensagens/mês, tempo de setup). Publicar como "Caso real Datafy" nas páginas e como reviews.
- Pedir avaliações no G2, Capterra e B2B Stack (criar o perfil primeiro).

## 6. Listas "melhores APIs de WhatsApp" que já existem
- O /monitorar vai mostrar quais URLs as IAs citam para "melhor API oficial do WhatsApp Brasil". Para cada uma: email pedindo inclusão, com o diferencial (Embedded Signup sem BM verificada, coexistência, preço por número sem markup).

- Moeda de troca: um dado original por trimestre ("Analisamos X mil números conectados: Y% vieram de API não oficial; tempo médio de migração Z"). Pitch para Startupi, Baguete, Mobile Time, podcasts de no-code/IA.
